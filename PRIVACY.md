# Política de privacidade — Windows Sticky Notes

O Windows Sticky Notes mantém títulos, textos, imagens, cores e posições das notas no computador do usuário. Não exige conta, não inclui anúncios, telemetria ou análise de uso e não envia o conteúdo das notas a servidores.

O usuário pode importar imagens locais, colar imagens da área de transferência, exportar backups ZIP e abrir a pasta de dados. Backups contêm o texto e as imagens; quem tiver acesso a eles poderá ler esse conteúdo. O aplicativo não adiciona criptografia própria.

Dados são gravados na pasta de dados do perfil do Windows. Na versão MSIX, o Windows pode gerenciar/virtualizar a pasta no contêiner do pacote. As versões portátil e Store não devem ser tratadas como sincronizadas; use backup para transferência. A lixeira do aplicativo conserva notas recuperáveis. A desinstalação portátil preserva os dados; antes de remover/redefinir uma instalação da Store, exporte seu backup.

Atualizações pela Microsoft Store seguem as configurações e políticas da Microsoft. Downloads pelo GitHub seguem as políticas do GitHub. Esses serviços podem coletar dados próprios, independentemente do aplicativo. O app não consulta a rede para atualização automática; o Windows/Store gerencia a instalação da versão Store.

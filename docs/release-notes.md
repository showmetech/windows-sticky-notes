# Windows Sticky Notes 1.1.0

- Pacotes independentes para Windows 11 x64 e ARM64, incluindo o runtime .NET.
- Inicialização compatível com o gerenciamento nativo do Windows na versão MSIX.
- Versão exibida nas configurações vem do mesmo identificador usado nos pacotes.
- Fluxo único para código, builds, testes, GitHub Release e submissão à Microsoft Store.

Notas: a publicação na Store depende de cadastro empresarial aprovado, identidade oficial, primeira submissão e certificação. Compilar e validar pacotes não equivale a aprovar a versão na Store. A versão desktop existente permanece preservada enquanto esses canais não estiverem alinhados.
